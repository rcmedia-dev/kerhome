Como apresentar (demo viva)

Prima Play 90s para correr as 6 cenas com os tempos reais do vídeo (6/12/17/15/20/20s). Use Cena para pausar e explicar cada bloco ao cliente. O palco é 1920×1080 e escala sozinho ao ecrã — ideal para projetor ou call.

Transições aplicadas: fade-to-white · match-cut (casa→mapa) · typewriter · stagger · morph check→chave · contadores · blur-reveal no CTA. Eases: power2.inOut / power3.out / back.out. Ícones: lucide-react 0.522.0, a mesma biblioteca do produto.

Levar para Hyperframes (render mp4)

1) npx skills add heygen-com/hyperframes → Core Skills → reinicie o agent.
2) Cole o ficheiro hyperframes.prompt.md com /hyperframes.
3) npx hyperframes lint → check → snapshot --at 0,6,18,35,50,70 → render --output kercasa-90s.mp4.

Assets: kercasa_logo.png · house1…21.jpg · background-audio.mp3 (fundo, ajustado a 90s) + SFX em video/assets/mix.mp3 · MP4 em renders/kercasa-90s.mp4.
